# Security Policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Contact the
maintainer privately through the email listed in `pyproject.toml` or GitHub's
private vulnerability reporting feature for this repository.

Include the affected version, a description of the issue, and steps to reproduce
it. Do not include real API credentials or personal data in a report.
